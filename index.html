  How cross-device P2P works

If you and the shop are using the same device or browser (for example testing on one laptop), the link is instant with nothing to scan. On separate phones, a real direct WebRTC connection is opened after a one-time QR scan - this is genuine peer-to-peer, not simulated, but on strict mobile-carrier networks a P2P link can occasionally fail to establish; if that happens, reopening the app still shows every post the shop has published.
